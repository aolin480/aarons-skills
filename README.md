# Aaron's skills

Public agent skills maintained by Aaron Olin.

## TaskForge MCP

Install the TaskForge workflow skill globally:

```sh
npx skills add https://github.com/aolin480/aarons-skills --skill taskforge-mcp -g -y
```

This repository contains agent instructions only. The TaskForge MCP runtime is distributed
separately as the private `@aolin480/taskforge` package.
