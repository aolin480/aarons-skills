# Bounded worker packet

Use only when the user authorizes delegation and the native host exposes the
needed controls. Do not infer delegation from this template or ticket metadata.

- Request and exact deliverable:
- Authoritative server, workspace, task, and parent IDs:
- Repository root, allowed files, and forbidden paths:
- Exact integration base and current head:
- Settled interfaces, assumptions, and constraints:
- Applicable instruction and canonical reference paths:
- Required prerequisites and actual read receipts:
- Acceptance criteria and exact checks:
- Evidence to return and next permitted action:

The worker reads its applicable local instructions and current execution packet.
It verifies its own tool and filesystem access. It must preserve concurrent work
and return an unresolved architecture question to the parent instead of expanding
scope. No TaskForge writes, merges, or approval decisions are delegated implicitly.

Return changed files, exact revisions or uncommitted state, decisions applied,
commands and actual outcomes, failures, and residual risk. The parent inspects
the complete integrated diff and invalidates affected evidence after corrections.
